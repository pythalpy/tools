Welcome to the Quran Audio Downloader Tool 

# How to use: 
1) Visit quranicaudio.com and select 'Download' on a sura from a recitor.
Grab the recitor name portion of the download url.
e.g. for https://download.quranicaudio.com/quran/sudais_and_shuraim_with_urdu/034.mp3
    select `sudais_and_shuraim_with_urdu`. 

    and for
    https://download.quranicaudio.com/quran/sa3d_al-ghaamidi/complete/034.mp3

    select `sa3d_al-ghaamidi/complete`

2) Add the name to the list_of_recitors below. Some recitors have been pre-populated
as an example. Disable specific lines with a #.

3) Set your local_download_directory as the path to contain the audio downloads.
    Files will be downloaded to the 'recitor_name' subfolder.
    
4) Set the range of Surahs [first, last] to download. e.g. 

    Only Surah Yaseen: 

    `range_of_surahs = (36)`
    
    All of Juz Amma

    `range_of_surahs = (78, 114)`

    Sura Al-Fatiha, Al-Baqarah, and Al-Imran

    `range_of_surahs = (1, 3)`

5) Download surahs as needed. 

# Notes:
